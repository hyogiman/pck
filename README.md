# 생각의 텃밭 V0.3

이번 버전의 핵심은 **Home을 대시보드가 아니라 Capture 도구로 바꾼 것**입니다.

## Home
- 앱 제목
- 오늘 날짜
- 가운데 큰 `생각 남기기` 버튼
- 오늘 작성한 생각 개수
- 오늘 개수를 누르면 오늘의 기록만 확인

통계, 과거 기록, 최근 Library, 성장 중 Thread 등은 Home에서 제거했습니다.

## Capture
처음 입력할 때는 분류하지 않습니다.

1. `내 생각`을 바로 입력
2. 필요할 때만 `문장 · 장면 · 누군가의 말`을 펼쳐 추가
3. 저장

저장 뒤에는 세 가지 선택만 나옵니다.

- 그냥 끝내기
- Library에 연결
- Thread에 연결

기본값은 **그냥 끝내기**입니다.

## 서점에서 책 한 문장을 발견했을 때
1. 앱 실행
2. `생각 남기기`
3. 내 생각 + 책의 문장 입력
4. 저장
5. `Library에 연결`
6. 기존 책이 있으면 선택
7. 없으면 그때 책을 한 번만 등록

이후 같은 책의 기록은 동일한 Source 아래 계속 쌓입니다.

## Thread
Thread는 매번 기록할 때 선택하는 분류가 아닙니다.
생각이 쌓인 뒤 '전에 했던 생각과 닮았다'고 느껴질 때 연결하는 후처리 기능입니다.

## 데이터 / Firebase
Firestore 구조와 Security Rules는 V0.2와 동일합니다.
따라서 기존 Rules를 그대로 사용하면 됩니다.
